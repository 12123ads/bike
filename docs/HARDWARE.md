# 电瓶车定位 + 手机开锁：硬件与决策

> 这份是给你看的：**买什么、怎么接、哪些坑会烧板子、你还需要拍板什么**。
> 写代码需要的东西（引脚映射、AT 命令、协议报文、MQTT 契约）全在
> [`DESIGN.md`](DESIGN.md) 里，这里不重复。
> 两份文档冲突时以 `DESIGN.md` 为准，并且告诉我，我来改这一份。

## 1. 这台设备做什么

装在电瓶车上，从 48V 车电池取电（不装自己的电池）：

- **定位**：GPS/北斗定位，走 4G 上报到家里的服务器，在 Home Assistant 里能看到车在哪。
- **开锁**：手机 App 点一下就开锁（蓝牙，**锁屏状态下也能点**）。**只支持安卓；iPhone 技术上可做，当前没做。**
- **防盗感知**：车被动了会触发上报（靠加速度计），平时睡着省电。

## 3. 装的时候必须注意的 8 件事

前 7 条每一条都能让你白花钱或者烧掉板子；第 8 条是已经做过的那次上机检查，记下来免得重复踩。

**1. 保险丝要看直流耐压，不是交流。**
48V 电池充满是 58.8V。常见的「250V」保险丝标的是交流，直流分断能力远低于这个数。
必须选明确标注 **直流 ≥100V** 的型号。

**2. 板子到手第一件事是测静态电流，别急着焊。**
这批克隆板质量是抽奖：同款板子实测过 0.42 µA、7~8 µA、750 µA 三种结果，
差了 1700 倍。如果拿到的是 750 µA 那种，整个省电设计要重做——早测比晚测好。
**这一项到现在还没做**（2026-09-04 那次上机只查了芯片，没量电流），仍然是最该先做的事。
量的时候必须**拔掉调试器**冷启动：调试器接着的时候芯片的深睡是被仿真的，量出来是毫安级。

**3. 5V 只能灌 VBAT 焊盘。**
板子上有 VBUS、VCC、EXTVCC、VBAT 几个看起来都像电源的焊盘：

- 灌 **VBAT** ← 唯一正确
- 灌 VBUS → 会让板上的充电芯片在没有电池的回路里一直工作
- 灌 VCC / EXTVCC → **什么都没供上**，那是个输出脚，你在往一个稳压器的输出口倒电

**4. 5V 只剩 0.5V 余量，必须用示波器确认。**
芯片的绝对上限是 5.5V。LX-P160 输出 5V，只剩 0.5V 空间给它的精度误差和上电瞬间的过冲。
**上电瞬态超过 5.5V 就是永久损坏**，装机后先用示波器看一眼再接芯片。

**5. 开锁天线不用管了。**
这一条原来是「NFC 环形天线必须自己调、要 VNA 收敛两颗电容」。
**开锁改成蓝牙之后整块工作消失**：2.4 GHz 天线在开发板上，已经调好了。
顺带也不用再写那个一次性的 `UICR.NFCPINS`。

**6. 大电解电容自己会漏电。**
按「容量 × 电压 × 0.01」估漏流。在这个设计里，一颗选大了的电解电容
漏掉的电可以和整机待机耗电一样多。滤波电容别贪大。

**7. 电压采样那三只电阻不能随便换。**
这是唯一一处「买错阻值就烧芯片」的地方，而且烧了没法救。

比例必须是 **21:1**：上面两只 **4.7 MΩ** 串起来，下面一只 **470 kΩ**。

```
电池 PACK+ ──[4.7 MΩ]──[4.7 MΩ]──┬── 主控 P0.31 脚
                                 │
                             [470 kΩ]
                                 │
                        [小信号 N-MOS 门控] ── 电池 PACK-
```

三个原因，缺一条都不行：

- **芯片脚最多只能进 3.3 V。** 58.8 V ÷ 21 = 2.8 V，正好。用 1:1
  （上下都 1 MΩ）会进 29.4 V —— 差了将近 10 倍，通电即死。
- **上面为什么用两只而不是一只 9.4 MΩ。** 一只要承受 56 V，而 0603
  封装的贴片电阻标称耐压只有 75 V，0402 只有 50 V，余量太薄。
  拆成两只之后每只只担 28 V。
- **也不能换成 20 MΩ + 1 MΩ**（看起来更省电）：阻值太大，
  芯片的 ADC 来不及采准，读数会偏低，而且查不出来。

精度买 **1%** 的，5% 的会让电量显示飘几个百分点。

**换了别的电池就必须重算。**（60 V / 72 V 的车，或者换锂电）
固件里有一道编译期检查：比例不够会直接编译失败并提示，不会让你把错的板子焊出来。

**8. 主控板已经上机查过一次了（2026-09-04），结论是好板子。**

用 J-Link 接主控板背面那两个焊盘（丝印 `CLK` / `DIO`），另外两根线从排针取
（GND 和 3.3 V），四线全通，读芯片一路顺。查出来的东西：

- **芯片是真的 nRF52840**，正品批次（QIAA / AAC0），256 KB 内存 + 1 MB 存储，
  不是常见的翻新片或标错型号。
- **板子的 3.3 V 设置是对的**，不需要动。这一项如果错了板子根本起不来。
- **芯片没上锁**，能随便烧。
- **板子自带的 bootloader 正好是我们要的那一版**（nice!nano 0.6.0），不用换。
  以后升级固件就是「镊子点两下让它出现成 U 盘，把文件拖进去」。
- 板子上原来那份程序是别人留下的 Arduino 例程（Adafruit 的键盘/蓝牙那套），
  刷我们自己的固件会直接盖掉，不用管。

**同一次操作里踩了一个坑，已经修好了**：我跑了 J-Link 的一个写入测速命令
（`testwspeed`），它默认往芯片最前面 128 KB 写测试数据，把板子的蓝牙底层固件
（SoftDevice）擦了。后来下载官方镜像原样刷回去、逐字节校验通过，板子现在是好的。
**记下来：这块板子上不要跑 J-Link 的 `testwspeed` / `testcspeed` / `erase`。**

还有两件当时没做的：**静态电流没量**（见上面第 2 条），
**日志通路没验**（这块板子的日志只能靠调试器读，不能靠 USB 串口，
因为两个串口都被 4G 和 GPS 占了）。这两项都排在下一步。

### 接线总览

```
48V 电池 PACK+
   │
   ├─[保险丝 250~500mA，直流耐压≥100V]
   ├─[Q1 P-MOS 防反接]           ← 不要用肖特基二极管
   ├─[SMBJ58A TVS 到 PACK-]
   └─[LX-P160 模块] ──5V──→ 主控板 VBAT 焊盘   ← 只能是 VBAT
                                  │
        ┌─────────────────────────┼───────────────┐
        │              │          │               │
   LIS2DW12       ATGM336H    Air780EP          锁驱动
   (加速度计)      (GPS)       (4G)
    I2C 2线        串口2线      串口2线+2线

   蓝牙不在这张图里 —— 它是主控芯片自带的，天线在板上，一根线都不占。
```

外壳里还要留：**GPS 天线朝上、4G 天线避开金属**。
开锁那一面不再有天线要求（手机不用贴车，站在车边点手机就行）。

## 4. 会耗掉多少车电池

按 48V 20Ah（约 960 Wh）算：

| 工作方式 | 待机耗电 | 每天掉 | 停 3 个月掉 |
| --- | --- | --- | --- |
| **4G 常在线**（随时能远程查位置） | 0.5~1.5 mA | 0.06~0.18 % | **约 16 %** |
| **4G 定时开机**（只定时上报，查位置要等） | < 0.2 mA | < 0.024 % | 约 2 % |

**耗电大头是 4G 模组，不是主控芯片。** 主控自己只要 3 µA，可以忽略；
是 4G 模组要不要一直挂在网上，决定了上面这两行的差别。

所以设计上做成两档，平时用省电档。**这也是你要拍板的事之一（§7 第 2 条）。**

⚠ 这里说的是「设备偷偷耗掉的电」，不包括电池自己的自然损耗。
冬天几个月不骑的话，16% 是能感觉到的，2% 感觉不到。

## 5. 用起来是什么感觉

**开锁的实际动作：亮屏 → 在 App/锁屏小组件上点一下。两步。**

比原来的 NFC 方案（亮屏 → 解锁手机 → 打开 App → 贴车，四步）少两步，
而且**不用摸车**、**不用解锁手机** —— 蓝牙没有 NFC 那两道系统限制
（安卓在息屏或锁屏时根本不发 NFC 场，而且只允许前台 App 用 NFC）。
从点下去到锁开约 1~4 秒（App 已经在跑的话可以到 0.3 秒）。

**「手机在兜里走近就自动开」这个功能故意没做。** 两个理由：

1. **安全**：蓝牙可以从几十米外被「中继」—— 小偷用两台设备把车这边的信号
   转发到你家门口的手机那里，你的手机会诚实地完成一次开锁，车就开了。
   密码学挡不住这个，因为攻击者不需要解密，只是转发。
   要求「必须由你手动点一下」正是防这个的标准做法（NCC Group 对特斯拉和
   Kwikset 智能锁做出这个攻击后给的官方建议之一）。
2. **可靠性**：安卓会给后台 App 的蓝牙扫描降频到 5% 占空比，
   还可能直接把 App 杀掉。做出来会是「有时候走近就开，有时候站着等 15 秒
   还得掏手机」—— 一个防盗产品的失败方式必须是可解释的。

**iPhone 目前不支持，但技术上可做。** 这和 NFC 时代不同：NFC 在 iOS 上
需要苹果特批的 entitlement，而蓝牙不需要，iOS 甚至支持「后台被唤醒」。
要不要做是一个纯工作量问题，不是平台限制。

## 6. 你已经做的四个取舍，以及代价

这四条都是你主动定的，不是漏掉的。代价写在这里，将来别忘：

| 取舍 | 代价 |
| --- | --- |
| **不装备份电池** | 有人**剪线或拔电池，设备立刻断电死掉**，收不到「被断电」「被拖走」的告警。商用产品（如 Teltonika）都是靠一颗小电池撑这段时间的 |
| **不做硬件欠压保护** | 改成软件判断电压，靠固件降频上报 + 在 HA 报警。极端情况（固件挂了）就没有保护，只能靠电池组自己的 BMS |
| **不做「走近自动开锁」** | 必须手动点一下才开。这是防中继攻击的取舍，见 §5 |
| **暂不做 iPhone App** | 家里有 iPhone 的人只能用机械钥匙。**这一条不再是平台限制**（蓝牙在 iOS 上可行），是工作量取舍，将来可以补 |

**机械钥匙必须保留，这不是可选项。**
手机没电、手机丢了、4G 挂了、设备坏了——任何一种都会把你锁在车外面。

⚠ 另外记一笔：**将来如果改主意要加备份电池，必须同时加温度检测。**
0°C 以下给锂电池充电会析锂、有起火风险，这条要求在早前的方案迭代里被误删过一次。

## 7. 需要你拍板的事

按急迫程度排。前三条不定，对应的活就没法开工。
第 6 条是这次改蓝牙新增的，不定也能先施工，但发 App 之前必须定。

**1. 锁用什么？**
电磁锁（通电就开、断电锁上）还是电机锁（转一下）？
这决定了驱动电路、要几根线、以及功耗。**这一项不定，锁相关的元件全都不能买。**
顺带确认车上原来的锁怎么处理——是替换还是并联加一把。

**2. 远程查位置能等多久？**
- 「点一下几秒钟就要看到」→ 4G 要常在线 → 停 3 个月掉 16% 电
- 「等下一次自动上报（比如 5~30 分钟）也行」→ 掉 2% 电，而且电路更简单

**这个问题的答案直接决定上面 §4 那张表走哪一行。** 我的建议是后者：
开锁本来就是离线的，不依赖 4G，那 4G 常在线唯一的用处就是「立刻查位置」，
为这一个功能付 8 倍的电费不太值。

**3. Home Assistant 那台机器和这台机器怎么连？**
同一个内网 / 走 WireGuard / 走公网？
如果要走公网，MQTT 必须加密，否则等于把你所有车的位置公开广播。

**4. ~~要不要换 Air780EPM~~ —— 你已经定了：不换。**
继续用 Air780EP，AT 那一层的代码自己写。代价是最难调的那 2000~4000 行躲不过去，
已经写了一部分（断线重连和睡眠唤醒还缺，见 `FIRMWARE.md`）。

**5. 一件需要你批准的操作。** ~~上报要用的 MQTT 服务器（`/opt/mqtt`）现在缺权限隔离配置。~~
**已不需要**：服务端自己内置了 MQTT broker（因为你只有一辆车），不再动 `/opt/mqtt`。
顺带查到那个 Mosquitto 其实一直没在运行。

**6. 蓝牙相关的两件事（改蓝牙之后新增）。**

- **最低支持哪个安卓版本？** 定 **Android 12 以上**的话，App 只要一次
  「附近的设备」授权，完全不碰位置权限。要兼容 Android 11 及更老的手机，
  就**必须要精确位置权限、而且用户的系统定位开关要一直开着**才能扫到车
  —— 这是安卓的硬规定，代码层面没有任何绕法。我的建议是定 12+。
- **车要不要「随机换蓝牙地址」？** 现在是固定地址，好处是手机可以直接按
  地址连、不用扫描（省掉上面那些权限）。代价是**一辆车可以被沿街扫描长期跟踪**。
  换成随机地址能防跟踪，但手机连之前必须先和车「配对」过，流程更绕。
  现在的折中是：**车静止 5 分钟后就停止广播**，不广播就扫不到。

## 8. 后面按什么顺序做

| 阶段 | 干什么 | 什么时候算过 |
| --- | --- | --- |
| R0~R1 | 环境搭起来（**烧录器已经通了**，见 §3 第 8 条）；**板子体检测静态电流**；确认日志读得到 | 拿到真实的耗电数字；能看到固件打印 |
| R2~R3 | 加速度计、蓝牙通 | 摇一下有反应；手机连上车有响应（**锁屏也能连**） |
| R4 | 开锁协议 | 录一次开锁再重放，必须开不了 |
| R5 | 服务器 + Home Assistant | 地图上能看到车 |
| R6 | 4G 上报 | 车真的把位置发上来了 |
| R7~R8 | GPS；装供电前端；调两档功耗 | 省电档 < 0.2 mA |
| R9 | 收尾：没信号时用基站定位、欠压报警 | 拔掉 GPS 天线也还能报个大概位置 |
